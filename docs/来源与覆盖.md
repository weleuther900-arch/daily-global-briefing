# 来源与覆盖

## 覆盖目标

Daily Global Briefing 的目标是降低人工智能、数字经济、经济政策与全球商业环境中的重要信息遗漏，而不是宣称全量抓取新闻。

当前注册表包含 **50 个来源入口**，分为 **8 个覆盖组**。一个覆盖组只有达到最小可用来源数时才被认为健康；正式任务会在关键覆盖不足时停止，而不是以质量下降的内容继续发布。

| 覆盖组 | 关注范围 | 最小可用入口 |
| --- | --- | ---: |
| 国际人工智能官方发布 | 模型、产品、基础设施、研究与公司公告 | 6 |
| 中国数字经济与宏观政策 | 产业、监管、数字基础设施和宏观政策 | 4 |
| 国际数字政策与监管 | 数字治理、科技监管与贸易规则 | 2 |
| 开发者与开源生态 | GitHub 发布、安全公告与开发者动态 | 1 |
| 中国宏观数据发布 | 关键宏观数据与官方发布节奏 | 1 |
| 美国宏观数据与政策发布 | 宏观数据、央行和联邦政策 | 3 |
| 国际组织与主要央行 | 国际贸易、增长、能源与货币政策 | 2 |
| 国际权威媒体综合观察 | 国际经济、商业、科技与地缘政治发现 | 3 |

## 来源类型

来源以原始材料优先，涵盖以下类别：

- 政府、监管机构、统计部门和公开政策数据库；
- 国际组织、中央银行和多边机构；
- 公司新闻室、投资者关系页面、研究与产品博客；
- GitHub 更新日志、项目发布页、热门项目与安全公告；
- 路透、BBC、美联社等权威媒体的公开入口；
- 限定机构的官方 X 帐号原帖（可选，需要自备 API 凭据）。

媒体、热门榜和社交平台主要用于发现线索。涉及数字、监管、财报或争议事实时，系统会优先回到官方公告、监管文件、公司材料或其他公开权威依据。

## 入选标准

候选进入成稿前至少会经过：

1. 主题相关性和固定二十四小时窗口检查；
2. HTTPS 域名白名单、重定向和公开访问状态检查；
3. 发布时间、可读正文与付费墙识别；
4. 硬性排除、事件聚类、中文标题相似度与历史去重；
5. 关键事实与具体来源 URL 绑定；
6. 结构化成稿、独立复核和确定性规则校验。

付费墙、无可核实公开时间、只有热度但缺少实质变化、来源冲突无法消解，或与项目主题无关的候选不会被自动放行。

## 已知边界

- 公共网站可能改变页面结构、限制自动访问或延迟更新，单一入口不能视为永久稳定。
- 地方监管网站、临时公告、线下活动或尚未公开材料可能先于登记来源出现。
- 有限来源集合无法保证不遗漏所有事件；覆盖组、巡检和交叉核对用于降低而非消除这种风险。
- 系统不抓取付费内容、不绕过访问控制，也不把社交热度当作事实依据。

## 添加来源

请先阅读 [贡献指南](../CONTRIBUTING.md)。来源由 [`config/sources.v1.json`](../config/sources.v1.json) 统一登记；每个入口需要明确类型、HTTPS 域名白名单、主题、发现规则和所属覆盖组。修改后运行：

```powershell
npm test
npm run discover
```

真实在线检查应在自己的环境中完成，并避免将抓取缓存或来源正文提交到 Git。
