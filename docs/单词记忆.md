# Memory 单词表

Memory 是晨报项目内的本地单词学习工具，不设置每日目标、学习数量、连续天数或“上次学习”字段。每个单词独立保留既有的 `Day1` 至 `Day29` 勾选，最后一列由旧的 `Day30` 改为 `Mastered`。

目录只有三个：

- `All`：全部单词。
- `Learning`：尚未勾选 `Mastered` 的单词。
- `Mastered`：已勾选 `Mastered` 的单词。

每个目录都按当前可见单词重新从 1 连续编号；编号只是目录内的显示顺序。勾选或取消 `Mastered` 不会改写 Day 勾选。旧词库导入时，已经勾选 `Day30` 的单词会自动转换为 `Mastered`。

## 使用

在私有部署目录运行：

```powershell
npm run memory
```

然后在浏览器打开 `http://127.0.0.1:4173`。词库保存为项目内、不会提交 GitHub 的 `state/memory-words.json`；可在页面中导入或导出 JSON。导入格式可以是 `{ "words": [...] }` 或单词数组，单词字段支持 `word`、`meaning`、`example`、`day1` 至 `day30`。
